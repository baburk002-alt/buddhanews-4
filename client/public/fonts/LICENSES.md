# Self-hosted font licenses

The WOFF2 files in this directory are self-hosted so the site does not send
reader requests to a third-party font CDN and the Content Security Policy can
keep `font-src` first-party.

| File | Family | License |
| --- | --- | --- |
| `fraunces-latin-var.woff2` | Fraunces | SIL Open Font License 1.1 |
| `manrope-latin-var.woff2` | Manrope | SIL Open Font License 1.1 |
| `vazirmatn-arabic-var.woff2` | Vazirmatn | SIL Open Font License 1.1 |
| `vazirmatn-latin-var.woff2` | Vazirmatn | SIL Open Font License 1.1 |

The SIL Open Font License permits bundling and self-hosting, including for
commercial sites, provided the fonts are not sold by themselves and any
redistribution keeps the license notice. Keep this file with the font files
when redistributing the project. The full license text is available from the
upstream projects:

- https://github.com/undercasetype/Fraunces
- https://github.com/sharanda/manrope
- https://github.com/rastikerdar/vazirmatn
